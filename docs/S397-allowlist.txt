Hi Studio 397 / LMU VR,

Please consider an Easy Anti-Cheat exception for one implicit OpenXR
API layer, the same class of exception granted to OpenXR Toolkit.

Layer name:  XR_APILAYER_NOVENDOR_sim_seat_lock
DLL:         XR_APILAYER_NOVENDOR_sim_seat_lock.dll
Project:     https://github.com/Bohn101/sim-seat-lock
What it does: motion-rig seat-lock. It intercepts xrLocateViews and
applies T_view = T_cor * inv(T_rig) * inv(T_cor) * T_hmd so the
eyepoint stays in the bucket while a 6DOF platform moves. It does not
read or write game memory, telemetry, inputs, or files under the LMU
install. Pose comes from a serial IMU in a separate process.

Reproduction with the layer enabled (Steam VR Mode / OpenXR Mode):
  "Unable to start the game in VR mode. Check the log for more info."
With the layer disabled, official VR starts.

Hardware: PSVR2 + official PC adapter, SteamVR OpenXR runtime
